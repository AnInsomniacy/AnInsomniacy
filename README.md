**The Rayburst stack**

- [**Rayburst**](https://github.com/AnInsomniacy/rayburst): download manager for macOS, Windows and Linux. HTTP, BitTorrent, ED2K, HLS/DASH. [rayburst.pages.dev](https://rayburst.pages.dev)
- [**Rayburst Connect**](https://github.com/AnInsomniacy/rayburst-connect): browser extension for Chrome, Edge and Firefox that sends downloads to Rayburst
- [**Aria2 Next**](https://github.com/AnInsomniacy/aria2-next): aria2's CLI and JSON-RPC on a rebuilt engine (libcurl, libtorrent, FFmpeg)
- [**raria**](https://github.com/AnInsomniacy/raria): experimental Rust-native download engine

**Vision for racket sports**, where my research meets my hobby 🏸

- [**TrackNet Series**](https://github.com/AnInsomniacy/tracknet-series-pytorch): real-time tracking of small, fast objects in sports video, PyTorch, pre-trained models
- [**Badminton AI Vision**](https://github.com/AnInsomniacy/badminton-ai-vision): player movement, distance and speed analysis for badminton matches

**Side projects**

- [**songsmith**](https://github.com/AnInsomniacy/songsmith): turns songs into illustrated lyric films
- [**turdus-m3rula-gui**](https://github.com/AnInsomniacy/turdus-m3rula-gui): GUI for an iOS/iPadOS downgrade tool
